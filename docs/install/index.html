Install Offsight Operations Bot

Add the internal operations and access-management bot to Discord.

Offsight Operations Bot is an internal Discord application used for:

  • Work email verification
  • Role and access management
  • Team channel permissions
  • Operational workflows

Installation should be completed only by an authorized server administrator. The bot requests only the permissions needed to manage access and support its workflows.

Install to Discord

Configuration required: replace DISCORD_CLIENT_ID with the bot's Discord application client ID before publishing.

Requested permissions

  • View Channels
  • Send Messages
  • Read Message History
  • Embed Links
  • Manage Roles
  • Manage Channels
