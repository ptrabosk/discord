# Welcome: Start Here

Follow these steps once to get access to your team channels.

1. **Click Verify Work Email** above.
2. **Enter your Discord account email.** Use the email your team lead has on the Discord Access roster. Other addresses will not work.
3. **Enter the 6-digit code** we email to that address. The code expires after 10 minutes. Use "Use a different email" if you typed the wrong address.
4. **Access is applied right away.** Your team channels appear as soon as verification finishes. If nothing shows up after a few minutes, close and reopen Discord.

If verification fails, check that you're using the correct email. If it still fails, contact Petra.
